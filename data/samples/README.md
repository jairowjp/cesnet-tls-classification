# Muestras publicadas

Archivos generados con `scripts/02_crear_muestra_app.py` a partir del mes de prueba (octubre de 2022):

| Archivo | Contenido |
|---|---|
| `muestra_prueba_octubre.parquet` | Hasta 300 flujos por categoría, que ningún modelo usa para entrenar. La usa la aplicación web |
| `plantilla_clasificador.csv` | Cinco flujos de ejemplo con el formato exacto de columnas que acepta el clasificador |
